Entities

PriceList

Individual catalogue item with code, description, category, subcategory, unit of measure, price, and percentage breakdowns (safety, labour, material, equipment).

Base Item

Assembly

Package of one or more price list items with a quantity multiplier. Contains name, category, type (FixedQuantity / QuantityFactor), value, and driver flag.

Estimation Workflow

The architecture supports an agentic estimation pipeline:

  1. Search — AI agent queries relevant PriceList items via MCP tools
  2. Package — Items are grouped into Assemblies with quantities and type
  3. Calculate — Each Assembly produces a cost estimate using its items, quantities, and percentage breakdowns
  4. Iterate — The agent refines the estimate by selecting alternative items or adjusting assembly composition
